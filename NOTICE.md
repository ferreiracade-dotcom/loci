# Third-party content notice

Loci bundles third-party content under `resources/`. Provenance and license status are listed here; "unconfirmed" means the license has not been verified.

## Scripture (`resources/scripture/`)

| Content | Source | License status |
| --- | --- | --- |
| Berean Standard Bible text (`BSB.json`) | Berean Bible Translation Committee, bereanbible.com | Dedicated to the public domain (2023) by the committee |
| BSB tables / interlinear (`interlinear/`) | Berean Bible Translation Committee, bereanbible.com | Dedicated to the public domain (2023) by the committee |
| Berean Literal Bible, draft (`BLB.json`) | literalbible.com | Source file header states it is dedicated to the public domain |
| BSB topical index (`topics.json`) | Source xlsx from bereanbible.com | The source xlsx states no license. It merges Torrey's, Nave's, OpenBible.info and BibleHub topics; the project owner has reviewed it and accepts bundling it. Attribution: topical data includes OpenBible.info (typically CC BY) and Bible Hub. |

BSB audio is not bundled; it is fetched at runtime from bible.helloao.org (Free Use Bible API).

## Other bundled resources

| Folder | Provenance |
| --- | --- |
| `resources/fathers/` | Ante-Nicene, Nicene and Post-Nicene Fathers (public-domain translations, 1885-1900) as ThML from the Christian Classics Ethereal Library (ccel.org), which allows personal, educational and non-profit use. |
| `resources/commentaries/` | A mix of sources: public-domain English editions (Bengel, Hengstenberg, Philippi, *The Lutheran Commentary*); Leupold's *Exposition of Genesis* (1942; no copyright renewal found, to be confirmed); SermonIndex MyBible modules (non-commercial use); and Calov, Gerhard, Heshusius and Melanchthon, whose Latin originals are public domain and whose English translations were obtained from The Faith Received (Mere Orthodoxy), which publishes no license for them. |
| `resources/dogmatics/` | Public-domain Latin originals (Baier, Calov, Hollaz, Hutter, Meisner, Musaeus, Quenstedt). The English translations come from The Faith Received (Mere Orthodoxy), which publishes no license for them; Baier's 1686 English is credited to Kaden Green. |

Where a source states no license, none is asserted here. If you are a rights holder and want a file removed or credited differently, please open an issue.
